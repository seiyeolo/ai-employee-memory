# 디자인 리뷰 체크리스트

> 디자인부가 산출물을 내보내기 전, 그리고 다른 부서 결과물을 검수할 때 쓰는 기준.
> 하나라도 ❌면 내보내지 않는다.

---

## A. 브랜드 정확성 (틀리면 즉시 반려)
- [ ] 제품명이 "퍼팅**미터**"로 표기되었는가 (× 퍼팅연습기)
- [ ] 회사명 표기: **(주)퍼티스트 / PUTTIST**
- [ ] 슬로건 원문 그대로인가: `3-putt Killer` / `The Zeroth Green` / `The 1st Putting Distance Meter in Golf`
- [ ] 두 브랜드(퍼티스트 / 셀러드)의 로고·컬러가 한 화면에 섞이지 않았는가
- [ ] 고객센터 `1644-9663`, 웹 `www.puttist.com` 등 표기가 `COMPANY.md`와 일치하는가
- [ ] 제품 라인업(일반형/고급형/일본형/미국형)이 해당 채널에 맞는 사양인가

## B. 시스템 준수
- [ ] 사용한 모든 컬러가 `디자인_시스템.md`에 정의된 값인가 (임의 hex 금지)
- [ ] 폰트가 Plus Jakarta Sans / JetBrains Mono인가 (셀러드 기준)
- [ ] 폰트 크기가 타입 스케일 안의 값인가
- [ ] 간격이 간격 스케일(8/10/12/20/24/32) 안의 값인가
- [ ] 한 화면의 폰트 크기 단계가 4개 이하인가

## C. 위계 / 판단
- [ ] 이 화면에서 사용자가 내려야 할 결정이 **하나**인가
- [ ] 주 버튼(Primary)이 하나뿐인가
- [ ] 가장 큰 요소가 가장 중요한 요소인가
- [ ] 숫자가 있다면 숫자가 주인공인가 (모노스페이스, 최대 크기, 단위는 작게)

## D. 제품 표현
- [ ] 화이트 제품이 배경에 묻히지 않는가 (배경 분리 확인)
- [ ] 제품 주변 여백이 제품 폭의 15% 이상인가
- [ ] 그래픽·텍스트가 제품을 가리지 않는가
- [ ] 제품 이미지가 현행 모델(퍼티스트 II)인가 — 구모델 이미지 혼입 확인

## E. 접근성 (수치로 확인, 눈으로 판단 금지)
- [ ] 본문 텍스트 대비 ≥ 4.5:1
- [ ] 큰 텍스트(≥24px 또는 ≥18.66px bold) 대비 ≥ 3:1
- [ ] `#2ECC71` / `#F39C12` / `#9CA3AF` 위에 텍스트를 올리지 않았는가
- [ ] 터치 타겟 ≥ 44×44px
- [ ] 컬러만으로 정보를 구분하지 않는가 (라벨·아이콘 병행)

## F. 반응형 / 실물
- [ ] 모바일 폭(360px)에서 가로 스크롤이 생기지 않는가
- [ ] 표·이미지가 컨테이너 안에서 스크롤되는가
- [ ] (인쇄물) 재단 여백·해상도(300dpi)·CMYK 확인했는가
- [ ] (인쇄물) 국가별 언어 사양이 맞는가 — 일본형=영어+일어, 미국형=영어

## G. 되돌릴 수 있는가
- [ ] 인쇄/발주/채널 게시 건이면 오케스트레이터 승인을 받았는가
- [ ] 기존 자산을 덮어쓰는 것이 아니라 새 버전으로 남기는가
- [ ] 결정 근거를 `data/디자인_결정로그.md`에 기록했는가

## 반려 시 전달 형식
```
[디자인 반려]
대상: (파일/화면)
위반 항목: (체크리스트 코드, 예: E-1 본문 대비 2.1:1)
근거: (측정값 또는 문서 조항)
대안: (구체적 수정값 — "더 진하게"가 아니라 "#1E8449로")
```
"애매하다", "좀 별로다"는 반려 사유가 아니다. 항목과 수치로 말한다.
