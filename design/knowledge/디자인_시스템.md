# 디자인 시스템 (Design System)

> 디자인부 단일 출처(Single Source of Truth).
> **여기에 없는 컬러·폰트·간격은 사용하지 않는다.** 필요하면 먼저 여기에 추가하고 쓴다.
> 최초 작성: 2026-08-12 (디자인부 신설)

---

## 0. 브랜드는 두 개다 — 섞지 않는다

| | 퍼티스트 (PUTTIST) | 셀러드 (sellerd) |
|---|---|---|
| 대상 | 골프 디지털 퍼팅미터 (하드웨어) | AI 온라인 회사 (서비스) |
| 고객 | 골퍼, 대리점, 학교/공공기관, 해외 바이어 | 온라인 셀러 |
| 성격 | 정밀 계측기 — 절제, 신뢰, 화이트 | 도구 — 명료, 속도, 그린 |
| 상태 | 컬러 시스템 **미확정** (§2 참조) | 컬러 시스템 확정 (§1) |

한 화면에 두 브랜드의 컬러·로고를 함께 쓰지 않는다.

### 1.2 타이포그래피

| 역할 | 폰트 | 비고 |
|------|------|------|
| 기본 | **Plus Jakarta Sans** (400/500/600/700/800) | 헤드라인은 800, 소제목 700 |
| 숫자·코드·데이터 | **JetBrains Mono** (500/700) | 숫자가 주인공일 때 반드시 모노 |
| 폴백 | `-apple-system, sans-serif` | |

**타입 스케일** (실사용값 기준)
`12 · 13 · 14 · 16 · 18 · 20 · 22 · 24 · 28 · 32 · 36 · 40 · 56 (px)`
- 본문 = 16, 캡션 = 13, 라벨 = 12
- 40px 이상은 `letter-spacing: -1px` 적용 (큰 글자는 자간을 좁힌다)
- 한 화면에서 서로 다른 크기는 4단계 이하로 유지

### 1.3 간격 / 형태
- 간격 스케일: `8 · 10 · 12 · 20 · 24 · 32 (px)` — 임의값 금지
- 라운드: 작은 요소 `9~10px`, 카드 `14~16px`, 큰 섹션 `20px`
- 네비게이션: 높이 `64px`, `rgba(255,255,255,0.9)` + `backdrop-filter: blur(20px)`

### 1.4 로고 규정
- 워드마크: `seller` + `d`. **`d`만** JetBrains Mono + `--green`. 나머지는 Plus Jakarta Sans 800, `--navy`
- 심볼: 네이비 라운드 사각형 안에 화이트 `S`
- 한글 병기는 `(셀러드)` 형태, 워드마크 우측
- 상표출원 기준 파일: `research/sellerd-logo-trademark.html` — **임의 수정 금지**

## 2. 퍼티스트 (PUTTIST) — 미확정 ⚠️

**현재 이 저장소에 퍼티스트 브랜드의 컬러/타이포 시스템 문서가 존재하지 않는다.**
확정 전까지는 아래 사실 기반 제약만 지키고, 새 컬러를 임의로 만들지 않는다.

### 2.1 확인된 사실 (제품·문서 기반)
- 제품: 화이트 바디 + 화이트 디스플레이 → **화이트/뉴트럴이 제품의 기본값**
- LASER READY: 적색 그라운드 레이저 → 레드는 제품 기능색이므로 UI 강조색으로 남용하지 않는다
- 슬로건 표기(고정): `3-putt Killer` / `The Zeroth Green` / `The 1st Putting Distance Meter in Golf`
- 제품명 표기(고정): **퍼팅미터** (× 퍼팅연습기)
- 제품 라인업 4종: 일반형 / 고급형 / 일본형(영어+일어 매뉴얼) / 미국형 — 패키지·매뉴얼 사양이 각각 다름

### 2.2 확정 필요 항목 (파이오니어 승인 대기)
- [ ] 브랜드 프라이머리 컬러 (골프 그린 계열 여부)
- [ ] 국문/영문 서체 지정
- [ ] 로고 사용 규정 (여백, 최소 크기, 금지 사용례)
- [ ] 패키지 4종 공통 레이아웃 규격
- [ ] 대리점 5곳의 로고·이미지 사용 허용 범위

## 3. 컴포넌트 규칙

### 3.1 버튼
- 한 화면에 **주 버튼(Primary)은 하나**. 나머지는 모두 보조(Secondary/Ghost)
- 보조 버튼은 `background: transparent` + 텍스트 `--text`
- 최소 터치 영역 44×44px

### 3.2 숫자 표시 (브랜드 핵심)
우리가 파는 것은 "숫자로 보이는 성취감"이다. 숫자 표시는 다음을 따른다.
- 숫자: JetBrains Mono 700, 화면에서 가장 큰 크기
- 단위(m, ft): 숫자의 40~50% 크기, `--text-muted`
- 숫자와 단위 사이 간격은 `4~8px`, 줄바꿈 금지

### 3.3 제품 이미지
- 화이트 제품 → 배경은 `--surface`가 아닌 `--bg` 또는 미묘한 그레이로 분리
- 제품 주변 여백 최소 = 제품 폭의 15%
- 그래픽·텍스트가 제품 위를 덮지 않는다

## 4. 접근성 기준 (반려 사유)

측정 기준: WCAG 2.1 AA — 본문 4.5:1, 큰 텍스트(≥24px 또는 ≥18.66px bold) 3:1

흰 배경(#FFFFFF) 대비 실측값:

| 컬러 | 대비 | 판정 |
|------|------|------|
| `#1A1A2E` 네이비 | 17.06:1 | ✅ 본문 가능 |
| `#16213E` | 15.89:1 | ✅ 본문 가능 |
| `#6B7280` 뮤티드 | 4.83:1 | ✅ 본문 가능 (경계선, 14px 이상 권장) |
| `#EF4444` 위험 | 3.76:1 | ⚠️ 큰 텍스트만 |
| `#27AE60` 다크그린 | 2.87:1 | ❌ 텍스트 금지 |
| `#9CA3AF` 라이트 | 2.54:1 | ❌ 텍스트 금지 — 장식/구분선 전용 |
| `#F39C12` 오렌지 | 2.19:1 | ❌ 텍스트 금지 — 면 전용 |
| `#2ECC71` 브랜드 그린 | 2.10:1 | ❌ 텍스트 금지 — 면 전용 |

**핵심 제약: `--green`(#2ECC71) 위에 흰 텍스트는 2.10:1로 AA 미달이다.**
그린 배경 버튼이 필요하면 접근형 그린을 쓴다:

| 접근형 그린 | 흰 텍스트 대비 |
|------|------|
| `#1E8449` | 4.72:1 ✅ |
| `#186A3B` | 6.64:1 ✅ |

→ 현행 랜딩페이지가 이 기준에 걸린다. `data/디자인_리뷰이력.md` DR-001 참조.
