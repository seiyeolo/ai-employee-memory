## DR-001 — 셀러드 랜딩페이지 주 버튼 대비 미달
- **일시:** 2026-08-12
- **대상:** `sellerd-landing/index.html` — `.btn-primary`
- **위반 항목:** E-1 (본문 대비 4.5:1), E-3 (#2ECC71 위 텍스트 금지)
- **현황:** `background: var(--green)` `#2ECC71` + `color: white`, `font-size: 14px / weight 700`
- **측정값:** 흰 텍스트 대비 **2.10:1** — AA 기준(4.5:1) 미달. 14px이므로 큰 텍스트 예외(3:1)도 적용 불가
- **영향 범위:** 페이지 내 주 버튼 5개소 (line 556, 573, 715, 729, 738) — 전 CTA가 해당
- **대안 (택1, 파이오니어 승인 필요):**
  - A. 버튼 배경만 접근형 그린 `#1E8449`(4.72:1) 또는 `#186A3B`(6.64:1)로 교체. 브랜드 그린 `#2ECC71`은 면·아이콘·그래픽에 유지
  - B. 주 버튼을 `--navy` `#1A1A2E`(17.06:1)로, 그린은 강조 요소로만 사용
- **상태:** ⏸ 보류 — **미수정.** 컬러 시스템 변경은 승인 사항이므로 임의 반영하지 않음
- **비고:** 그린 자체를 바꾸자는 것이 아니라, "그린 위 흰 글씨"만 성립하지 않는다는 지적이다.
  로고·그래픽의 `#2ECC71`은 그대로 둔다.

## DR-002 — 퍼티스트 브랜드 비주얼 시스템 부재
- **일시:** 2026-08-12
- **대상:** 저장소 전체
- **내용:** 주력 제품 브랜드인 퍼티스트의 컬러·타이포·로고 규정 문서가 저장소에 없다.
  콘텐츠부 `브랜딩_가이드라인.md`는 톤&매너(말하는 방식)만 다루고 비주얼 규정은 없다.
  현재 유일하게 문서화된 비주얼 시스템은 셀러드(서비스 브랜드)뿐이다.
- **리스크:** 상세페이지·패키지·매뉴얼이 제작자마다 다른 컬러/서체로 만들어질 수 있다.
  대리점 5곳의 자산 사용 규정도 없다.
- **필요 조치:** `../knowledge/디자인_시스템.md` §2.2 확정 필요 항목에 대한 파이오니어 결정
- **상태:** 🔴 대기 — 파이오니어 확인 필요
