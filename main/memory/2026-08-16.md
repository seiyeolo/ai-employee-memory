# 2026-08-16

## 롯데 프로젝트 - Perplexity Search SDK 검토 결정

- 오딘이 Perplexity Search SDK 문서(`https://docs.perplexity.ai/docs/search-sdk/overview`)를 공유하며 롯데프로젝트에 참고할 만한 툴인지 검토를 요청했다.
- 1차 판단: 참고 가치는 있으나 롯데 핵심 정제 파이프라인에 바로 도입하지 않는다.
- 적합한 용도: 공개 웹 근거 수집 보조, 시장/경쟁/상품 공개 근거 후보 수집, 고객 Q&A 준비.
- 부적합한 용도: 롯데/마켓링크 실데이터 외부 전송, SKU 속성 자동 확정, confidence score 직접 근거화.
- 결정: 참고 자료로 기록하고, 롯데 프로젝트 시작 단계에서 `public evidence adapter PoC` 후보로 재검토한다.
- 재검토 조건: synthetic/public SKU 5~30개, read-only, 비식별 키워드만 사용, 결과는 `candidate evidence` 및 `needs_human_review=Y`로 처리, 실제 데이터/API 비용/외부 전송은 오딘 승인 및 소라 게이트 후 진행.
