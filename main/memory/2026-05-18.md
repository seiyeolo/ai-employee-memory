## OpenClaw + Discord 리뷰 봇 셋업 진행 기록

- 오딘이 Discord Developer Portal에서 리뷰용 봇 앱을 만들었다. 처음 `Claude Bot` 계열 이름이 문제가 되어 `openclaw-reviewer` 계열 이름으로 진행했다.
- 봇 초대 권한은 최소 권한 중심으로 안내했다: 채널 보기, 메시지 보내기, 공개 스레드 만들기, 스레드에서 메시지 보내기, 링크 임베드, 파일 첨부, 메시지 기록 보기, 반응 추가, 빗금 명령어 사용, 외부 앱 사용. 관리자/모두 멘션/음성 권한은 제외 권장.
- 오딘이 OAuth2 URL Generator에서 `bot` 및 가능하면 `applications.commands` 스코프를 선택하고, 생성된 Discord OAuth URL을 브라우저 주소창에 붙여넣어 `odin_openclaw server`에 봇 초대를 완료했다.
- Discord 서버 화면에서 기존 OpenClaw 봇(`bot150...`)은 온라인, 새 리뷰용 봇(`openclaw-reviewer`)은 오프라인으로 확인됐다. 해석: 초대는 성공했지만 실행 프로그램/토큰 연결 전이라 오프라인.
- 오딘이 Bot Token을 초기화/복사했다. 토큰은 비밀번호와 같으므로 채팅/캡처로 공유하지 말라고 안내했다.
- 리뷰용 앱 Application ID: `1505674466514960384`.
- OpenClaw 설정 쪽에 reviewer 계정 자리를 만들고, 오딘이 로컬 `~/.openclaw/.env`에 `OPENCLAW_DISCORD_REVIEWER_TOKEN=...` 형태로 토큰을 직접 붙여넣도록 안내했다. 토큰 값은 기록하지 않는다.
- 협업 운영 규칙으로 저장한 핵심: Codex/OpenClaw는 Claude 리뷰를 무조건 수용하지 않는다. 항목별로 동의/비동의/부분동의를 판단하고, 합의된 수정만 구현한다.

## 오딘 안내 방식 메모

- 오딘이 복잡한 웹 UI에서 “새 탭에 열기”, “Generated URL”, “Permissions Integer” 같은 표현을 헷갈려했다. 앞으로는 “브라우저 위 주소창 클릭 → 붙여넣기 → Enter”처럼 화면 행동 단위로 안내하는 편이 좋다.
- 민감정보 단계에서는 “보내지 마세요/캡처에 나오면 안 됩니다/복사만 하세요”를 짧고 반복해서 안내하는 것이 안전했다.
