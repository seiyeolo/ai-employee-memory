# 2026-08-23

## 롯데 프로젝트 - OpenCode/Pi/Ollama 로컬 에이전트 후보

- 오딘이 OpenCode 에이전트를 이용해 Kimi, Qwen, DeepSeek, GLM 등을 Ollama에 설치하고 오픈소스/오픈웨이트 모델로 롯데 프로젝트에 활용할 수 있을 것 같다고 제안했다.
- 1차 판단: 가능성이 있다. `OpenCode -> Ollama -> 로컬 오픈웨이트 모델` 구조로 synthetic/public SKU 기반 PoC를 진행할 수 있다.
- 적용 원칙: 롯데 실데이터 외부 전송 금지, SKU 속성 자동 확정 금지, 후보 근거/정제 초안/검수 보조 역할로 제한한다.
- 오딘이 언급한 `Pi`는 Inflection의 대화형 Pi가 아니라 `pi.dev`의 오픈소스 터미널 코딩 에이전트 계열로 확인했다.
- 정정된 판단: OpenCode는 풀패키지형 코딩 에이전트, Pi는 미니멀하고 확장하기 쉬운 코딩 에이전트 하네스다. 롯데 전용 로컬 에이전트 커스터마이징 후보로 Pi를 2차 실험군에 포함한다.
- 우선순위: 1차는 OpenCode + Ollama + Qwen/DeepSeek/GLM/Kimi, 2차는 Pi + 동일 모델군 비교.
