## 오딘 피드백 - 영상/스크린샷 학습 결과는 구조 그림으로 보여주기
- 오딘이 "영상 학습 → 저장 → 의견 제시" 패턴만 반복하지 말고, 아키텍처 주제라면 실제 텍스트 아키텍처를 그려서 "이런 겁니다"라고 보여주는 방식이 더 좋겠다고 피드백했다.
- 앞으로 영상 또는 스크린샷 파일을 학습할 때, 내용이 시스템 구조/업무흐름/데이터흐름/조직 운영 구조라면 기본 응답에 ASCII 또는 Mermaid 스타일의 간단한 구조도를 포함한다.
- 권장 응답 패턴: `한 줄 결론 → 핵심 구조도 → 롯데/현재 프로젝트 적용도 → 지금 만들 것/보류할 것 → 저장 위치`.
- 단순 의견보다 오딘이 바로 판단할 수 있는 시각화 우선. 단, 고객 데이터/민감 정보는 구조도에 그대로 노출하지 않는다.

## 롯데 프로젝트 - Unstructured IO 적용성 검토
- 오딘이 `https://github.com/Unstructured-IO/unstructured`를 롯데 프로젝트에 사용할 수 있는지 확인 요청했다.
- GitHub 원문 기준 설명은 복잡한 문서를 LLM용 구조화 포맷으로 변환하는 오픈소스 ETL/문서 전처리 라이브러리다. 라이선스 Apache-2.0, 최신 릴리스 0.27.1(2026-08-21), Python 3.11~3.13 지원으로 확인했다.
- 지원 파일은 PDF, DOC/DOCX, XLS/XLSX, CSV/TSV, HTML, 이미지, PPT/PPTX, TXT, XML 등이며 partitioning/cleaning/extracting/chunking이 핵심이다.
- 공식 문서상 오픈소스 라이브러리는 production scenario용이 아니며 고급 OCR/VLM, 인증, 스케줄링, 모니터링, compliance, incremental loading 등이 제한된다.
- 판단: 롯데 SKU 정제 본엔진이 아니라 계약서/회신 PDF/제안서/기준표를 구조화하는 local-only `Document Intake Adapter` PoC 후보로 적합하다. 실데이터를 Unstructured API/Transform MCP/SaaS로 보내는 것은 승인 전 금지.
