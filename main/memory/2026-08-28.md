- 핵심 구조: 각 장비에 MHS driver를 붙이고, 장비 상태/명령/read-write primitive/안전 한계/자연어 태그/참조 파일을 표준화한다. 에이전트는 MCP, CLI, 코드 파일 API를 통해 여러 장비를 오케스트레이션한다.

- 셀르메스/롯데 적용 해석: 당장 물리 장비 제어가 아니라 `표준 드라이버 + 상태 사전 + 안전 한계 + 로그 + deterministic script` 사고방식을 데이터 정제/검수 하네스에 차용한다. 롯데에서는 SKU/Cell 처리기를 장비처럼 보고, 무분별한 에이전트 자율 실행이 아니라 Human QA와 승인 게이트를 둔다.
